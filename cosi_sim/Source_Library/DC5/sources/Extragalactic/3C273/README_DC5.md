## Model

DC2 average-state model (8.6e-4 ph/cm2/s, 0.1-10 MeV). Only change: the DC2 transmission-probability line is replaced with the DC3+ settings (range cuts, EarthOccultation false) and an EN terminator is added to the spectrum file.

## Change relative to the DC4 mock dataset

average state (Madsen et al. 2015), flux 8.6e-4 ph/cm2/s; DC2 transmission-probability line replaced by DC3+ settings

Any other README in this directory describes the original (DC2/DC3/DC4) model; where it conflicts with this file, this file describes what DC5 simulates.
