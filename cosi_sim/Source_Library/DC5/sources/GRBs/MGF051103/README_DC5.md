# MGF051103 — DC5

**DC5 status:** magnetar burst kept unchanged from DC4 (`DC3/sources/GRBs/MGF051103`); only the simulation inputs below are new.  
**Source:** select it in inputs.yaml as `DC5/sources/GRBs/MGF051103`

The spectral model, position, flux, polarization and light-curve shape are those of the DC3/DC4 definition. Any other README in this directory describes that model.

## MEGAlib simulation inputs (times relative to t_ref)

MEGAlib has trouble simulating short bursts at large absolute unix times, so this burst is simulated in times relative to **t_ref = 1835487300.0** (the first time of the DC4/DC5 orientation file):

- `GRB_051103_Sum_G1_G2_G3_shifted.dat`: the light curve with time − t_ref; the source file points to it. The original light curve with absolute times, `GRB_051103_Sum_G1_G2_G3.dat`, is kept for reference.
- `DC3_final_530km_3_month_with_slew_1sbins_GalacticEarth_cut_normed.ori`: the 3 orientation rows covering the burst, time − t_ref (46423–46425 s). This is the orientation file for the Cosima run. `DC3_final_530km_3_month_with_slew_1sbins_GalacticEarth_cut.ori` holds the same rows with absolute times.
- `sim_time_reference.txt`: t_ref and the burst window, absolute (1835533723.498–1835533724.022) and shifted (46423.498–46424.022).

After the Cosima run, add t_ref to the simulated event times to return to the absolute times of the orientation file. Generated by `scripts/make_sim_time_inputs.py`.
