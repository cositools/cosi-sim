# Cyg X-3 — DC5

**DC5 status:** modified  
**Based on:** `DC4/sources/Galactic/cygX3`  

## Model

One of the DC3 eqpair spectral-state models (state drawn at random among those not used in DC4) for the full 3 months, at nominal flux (no x7.9 boost).

## Change relative to the DC4 mock dataset

transition state replaced by the hypersoft state (DC3 Cangemi et al. 2021 models) for the full 3 months at nominal flux 0.001233 ph/cm2/s

Any other README in this directory describes the original (DC2/DC3/DC4) model; where it conflicts with this file, this file describes what DC5 simulates.

## References
