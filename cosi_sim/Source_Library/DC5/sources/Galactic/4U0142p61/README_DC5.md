# Magnetar 4U 0142+61 (new in DC5) — DC5

**DC5 status:** new (literature)  
**Position:** l = 129.384 deg, b = -0.4307 deg  

## Model

Steady hard tail (no pulsation light curve): log-parabola with local photon index 0.93 at 50 keV and the nuFnu peak at the reported ~228 keV break, normalised to F(20-229 keV) = 1.5e-10 erg/cm2/s. Flux 5.4e-4 ph/cm2/s (0.1-10 MeV).

## Change relative to the DC4 mock dataset

log-parabola, local index 0.93 at 50 keV with the nuFnu peak at 228 keV (beta=0.353); F(20-229 keV)=1.5e-10 erg/cm2/s (den Hartog et al. 2008); steady (no pulsation light curve)

Any other README in this directory describes the original (DC2/DC3/DC4) model; where it conflicts with this file, this file describes what DC5 simulates.
