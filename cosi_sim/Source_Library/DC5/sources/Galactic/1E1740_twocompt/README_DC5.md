# 1E 1740.7-2942 — DC5

**DC5 status:** modified  
**Based on:** `DC3/sources/Galactic/1E1740_compow -> DC3/sources/Galactic/1E1740_twocompt`  

## Model

Alternative DC3 spectral model: two thermal-Comptonisation components (twocompt). DC4 used the compow (Comptonisation + power law) model; both fit INTEGRAL data but differ strongly at the highest energies.

## Change relative to the DC4 mock dataset

swapped compow model for the alternative twocompt model (Bouchet et al. 2009)

Any other README in this directory describes the original (DC2/DC3/DC4) model; where it conflicts with this file, this file describes what DC5 simulates.

## References
