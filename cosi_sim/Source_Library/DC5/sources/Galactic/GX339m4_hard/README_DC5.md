# Black-hole binary GX 339-4, hard state (new in DC5) — DC5

**DC5 status:** new (literature)  
**Position:** l = 338.9391 deg, b = -4.3265 deg  

## Model

GX 339-4 in a moderately bright hard-state outburst lasting the full 3 months: cutoff power law Gamma = 1.6, Ecut = 200 keV, F(20-200 keV) = 1.5e-9 erg/cm2/s (~0.15 Crab in that band), 5% polarisation at 20 deg. Flux 2.9e-3 ph/cm2/s (0.1-10 MeV), ~5% of the Crab energy flux.

## Change relative to the DC4 mock dataset

black-hole LMXB in a moderately bright hard state for the full 3 months: Gamma=1.6, Ecut=200 keV, F(20-200 keV)=1.5e-9 erg/cm2/s; 5% polarisation

Any other README in this directory describes the original (DC2/DC3/DC4) model; where it conflicts with this file, this file describes what DC5 simulates.
