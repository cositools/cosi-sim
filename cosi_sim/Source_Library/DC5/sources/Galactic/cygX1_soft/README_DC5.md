# Cyg X-1 — DC5

**DC5 status:** modified  
**Based on:** `DC3/sources/Galactic/cygX1_hard -> DC3/sources/Galactic/cygX1_soft`  

## Model

Alternative DC3 spectral model: soft state (eqpair fit to INTEGRAL data) with 20% energy-independent polarisation, for the full 3 months. DC4 used the hard state.

## Change relative to the DC4 mock dataset

source in the soft state for the full 3 months (Cangemi et al. 2021 model)

Any other README in this directory describes the original (DC2/DC3/DC4) model; where it conflicts with this file, this file describes what DC5 simulates.
