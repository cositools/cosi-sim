# 26Al in the Carina region (new in DC5) — DC5

**DC5 status:** new (literature)  
**Position:** l = 287.6 deg, b = -0.6 deg  

## Model

1808.8 keV line (same width as the DC3 Cygnus model) from a 2 deg Gaussian centred on Trumpler 16 (l=287.6, b=-0.6) with 1.5e-5 ph/cm2/s, the SPI best-fit value of Voss et al. (2012).

## Change relative to the DC4 mock dataset

1809 keV line, 2 deg Gaussian at Trumpler 16, flux 1.5e-5 ph/cm2/s (Voss et al. 2012), width as DC3 Cygnus model

Any other README in this directory describes the original (DC2/DC3/DC4) model; where it conflicts with this file, this file describes what DC5 simulates.
